# Lessons

- 2026-04-04: Do not use product or marketing labels in package, directory, file, type, or symbol names unless the user explicitly asks for that naming. Default to neutral functional names like `focus-dashboard`, `daily-focus-plan`, or `today-dashboard`.
- 2026-04-05: When the user provides visual feedback that the UI "doesn't look good", do not keep tuning contrast or effects on the same composition. Re-evaluate the spatial hierarchy first and remove heavy containers before adding more styling.

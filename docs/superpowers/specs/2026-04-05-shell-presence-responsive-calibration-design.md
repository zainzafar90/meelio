# Shell Presence And Responsive Calibration Design

## Goal

Calibrate the ambient shell so it keeps its presence across bright and dark wallpapers, remains legible without harsh outlines, and holds together across different viewport sizes.

## Principles

- Keep the shell atmospheric, not flat.
- Pills should read as intentional shell chrome, not disappear into the wallpaper.
- Focus mode should feel slightly stronger and more immersive than home mode.
- Home and focus should keep the same visual family.
- Responsive behavior should preserve composition, not just shrink elements.

## Scope

- Ambient pill prominence
- Focus-shell blur and glass intensity
- Home/focus spacing and alignment at multiple viewport sizes
- Quote/dock relationship in shorter heights

## Non-Goals

- New features
- New data surfaces
- Large motion redesign

## Success Criteria

- Pills remain visible on bright and muted wallpapers.
- Focus mode has enough atmospheric blur to feel active.
- Timer surface feels integrated, not blocky or washed out.
- Layout remains balanced on narrower and shorter screens.
